Jarvis

A private, single-user personal assistant

Jarvis is a voice-driven personal assistant that runs on its owner's own computer. It answers questions from the owner's notes, and helps with everyday work such as checking the calendar, summarising unread email, drafting replies and finding files.

Who can use it: Jarvis is a personal tool for one person, its owner. It is not offered to the public, there is no sign-up, and it has no other users.

Google account access

With the owner's permission, Jarvis connects to the owner's own Google account in order to:

  • Gmail: read messages and create drafts. Jarvis does not send email on its own.
  • Google Calendar: read events, and add or change events only when the owner asks.
  • Google Sheets, Docs and Drive: find, read and create the owner's own files.

How this data is handled is described in the Privacy Policy.
