Privacy Policy

Jarvis · Last updated: 20 November 2026

Jarvis is a private personal assistant used by one person, its owner. It runs on the owner's own computer. This policy explains what Google account data Jarvis accesses, how it is used, and how it can be removed.

1. Data Jarvis accesses

Only after the owner signs in and grants permission, Jarvis can access the owner's own:

  • Gmail: message content and metadata (to search and summarise mail) and drafts (to create draft replies).
  • Google Calendar: events (to read the schedule and add events the owner asks for).
  • Google Sheets: spreadsheets (to read and add rows the owner asks for).
  • Google Drive and Docs: files (to find, read and create the owner's documents).

2. How the data is used

  • Data is used only to answer the owner's own requests: for example "what's on my calendar today?" or "summarise my unread email".
  • To produce an answer, the relevant text may be sent to the owner's own AI model provider account (Anthropic's Claude API), under the owner's own API key, and is used only to generate that answer.
  • Jarvis does not send email by itself, does not post publicly, and does not change calendar events unless the owner asks.

3. Sharing

Google user data is not sold, rented or shared with anyone, is not used for advertising, and is not used to train AI models. There are no other users and no third parties receive the data, apart from the AI processing described above, done on the owner's own behalf.

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Storage and security

  • Sign-in tokens are stored only on the owner's computer, in files readable only by the owner's account.
  • Email, calendar and file content is fetched when needed to answer a request and is not kept in a separate database.
  • All connections to Google use encrypted HTTPS.

5. Removing access and data

Access can be removed at any time at myaccount.google.com/connections (find "Jarvis" and remove it). Deleting the token files on the owner's computer also removes Jarvis's stored access.
